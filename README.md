# Relic LP

## 技術スタック
- **Node.js** : 24.19.0
- **Astro** : 7.2.6
- **SCSS** : 1.103.1

## 🧞 コマンド一覧
### セットアップ（パッケージのインストール）
```bash
npm install
```

### ローカルサーバーの起動
```bash
npm run dev
```

### ビルド （distフォルダへ生成）
```bash
npm run build
```
