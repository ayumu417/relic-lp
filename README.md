## 🧞 コマンド一覧

| コマンド                   | 実行される処理                                           
| :------------------------ | :-----------------------------------------------　
| `npm install`             | パッケージのインストール                   
| `npm run dev`             | ローカルサーバーの起動                             
| `npm run build`           | ビルド （`/dist/`フォルダへ）
